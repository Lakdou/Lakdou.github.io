SentimentAI

Des milliers d'avis clients, écrits dans la joie, la colère ou la déception. SentimentAI les lit, les comprend, et lève la main quand le monde change.Thousands of customer reviews, written in joy, anger or disappointment. SentimentAI reads them, understands them, and raises its hand when the world changes.

Scoring de sentiment avec un modèle LightGBM (TF-IDF), suivi et ré-entraîné via MLflow. En production : API FastAPI avec authentification et quotas, interface Streamlit expliquée par SHAP, Docker Compose derrière Nginx, monitoring Prometheus et Grafana avec détection de dérive (divergence KL), orchestration Airflow et versioning DVC.Sentiment scoring with a LightGBM model (TF-IDF), tracked and retrained with MLflow. In production: a FastAPI API with authentication and quotas, a Streamlit interface explained with SHAP, Docker Compose behind Nginx, Prometheus and Grafana monitoring with drift detection (KL divergence), Airflow orchestration and DVC data versioning.
